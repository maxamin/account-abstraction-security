# Contributing

Contributions are welcome: corrections, new chapters, case studies, and resources.

1. Chapters live in `chapters/NN-slug.md` and start with a single `# Title`.
2. Each chapter ends with `## Exercises` and `## Further reading`.
3. Cite primary sources (papers, post-mortems, repos). No unverifiable claims.
4. Offensive content must be educational and defensive in intent: no working exploits against live, unpatched targets, no weaponised malware.
5. Run `wikismith summary .` and `wikismith lint .` before opening a PR.
